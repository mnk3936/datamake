# DATAMAKE

A modern web application built with **React 19**, **TypeScript**, **Vite**, and **Tailwind CSS v4**.

## Development

- Start dev server:
  ```bash
  npm run dev
  ```
- Build for production:
  ```bash
  npm run build
  ```
- Preview production build:
  ```bash
  npm run preview
  ```
- Run linter:
  ```bash
  npm run lint
  ```
